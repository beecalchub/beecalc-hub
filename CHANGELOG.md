# BeeCalc Hub - Version History

The version number is set in `package.json` ("version"). It appears in the site footer
and in the name of each project zip (`beecalc-hub-vX.Y.Z.zip`).

## v2.0.0 - 2026-11-21
- Russian version of the whole site at /ru (all pages and all 142 calculators)
- Language menu with flags (French, Spanish, German, Romanian marked "coming soon")
- Search, tabs and category filter on the Russian "all calculators" page
- Metric switch now works in every calculator (inputs and results convert automatically)
- Russian contact page: emails open with subject only; questions shown on the page
- Version number shown in the footer

## v1.0.0 - 2026-04-18
- First public release: 142 calculators in English, donations, Google Analytics, sitemap
